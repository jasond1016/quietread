# QuietRead MVP 功能边界

## 产品定义

纯本地、单用户、无账号的 Android EPUB 阅读器。首版只验证一个闭环：

**导入 EPUB → 书架展示 → 分页阅读 → 自动续读 → 删除书籍**

借鉴微信读书克制的阅读交互，但采用 QuietRead 自有视觉，不复制其社交、运营或服务端能力。

## 核心功能

- 仅适配 Android 手机竖屏。
- 通过系统文件选择器导入单个 EPUB，并复制到应用私有目录。
- 支持无 DRM、可重排的 EPUB 2/3：
  - 书名、作者、封面
  - 章节目录
  - 正文样式与内嵌图片
  - EPUB 内部链接
- 书架展示封面、书名、作者、阅读进度，按最近阅读排序。
- 无封面或元数据缺失时使用占位封面及文件名。
- 相同内容重复导入时不新增书籍，直接定位已有书籍。
- 正文只提供左右分页阅读。
- 阅读器包含：
  - 点击中央显示或隐藏控制栏
  - 左右区域翻页
  - 目录跳转
  - 全书进度跳转
  - 字号调整
  - 浅色、深色主题
- 字号和主题为全局设置；每本书独立保存阅读位置。
- 重新启动或修改字号后，恢复到同一段正文附近，而非依赖旧页码。
- 从书架删除书籍时，经确认后同时删除内部副本及阅读记录。

## 最小数据与界面

- 仅保留一个持久化书籍记录，包含文件、元数据、最近阅读位置、进度和时间信息。
- 不单独建立作者、章节、书签、阅读历史等实体；目录和章节结构按需解析。
- 偏好设置只保存全局字号与主题。
- 只有两个一级界面：
  - 书架
  - 阅读器
- 导入、目录、进度和阅读设置均使用系统选择器、弹层或底部面板，不增加独立页面。

## 明确不做

- TXT、PDF、漫画及固定版式 EPUB
- DRM 内容
- 横屏、平板、双页模式
- 上下滚动阅读或阅读模式切换
- 书签、高亮、笔记、全文搜索
- 书架分类、自定义排序、批量管理、文件夹扫描
- 字体选择、行距、页边距、背景纹理、亮度控制
- 听书、朗读、词典、翻译
- 账号、同步、备份、推荐、排行、评论、社交
- 网络请求、远程图片或字体；应用不申请联网权限
- 统计、埋点、崩溃上报和广告

## 验收场景

- 可从系统文件选择器导入常见的无 DRM EPUB 2/3。
- 导入后即使原文件被移动或删除，仍可正常阅读。
- 目录、分页、内嵌图片和书内链接能够正常工作。
- 关闭应用后再次打开同一本书，可以回到此前正文位置。
- 调整字号后重新分页，阅读位置不会跳到其他章节。
- 深浅主题同时覆盖应用界面和 EPUB 正文。
- 重复导入同一本书不会产生重复条目。
- 损坏、加密或不支持的 EPUB 会给出明确错误，且不留下残缺书架记录。
- 删除书籍后，内部文件和对应阅读状态均被清除。
- 飞行模式及完全无网络环境下，全部功能正常工作。

## 默认约束

- 首版不追求覆盖所有 EPUB CSS 特性，以主流文字类 EPUB 的稳定阅读为准。
- 外部网页链接不在应用内打开；书内导航链接正常处理。
- 应用卸载会清除书籍副本及进度，首版不提供导出或恢复。
